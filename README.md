# MoodMate — Mood Tracking Web Application

MoodMate is a web-based mood tracking application designed to help users record their daily emotions and monitor their emotional patterns over time.

The application provides a simple way to document mood entries and review personal mood trends through weekly summaries.

## Features

- **Mood Tracking** — Record and manage daily mood entries.
- **Mood History** — Keep track of previously recorded moods.
- **Weekly Reports** — Review mood activity through weekly summaries.
- **Progress Tracking** — Save and review personal mood-tracking progress.

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL / SQL
